# NightShift — плагин "тёплого экрана" для PSP

Kernel-плагин для CFW (PRO CFW / ARK-4), который приглушает синий и зелёный
каналы экрана — как Night Shift на iOS, только для PSP.

## Сборка без ПК (только Android + GitHub)

1. Создай новый **публичный или приватный репозиторий** на GitHub (через
   приложение GitHub или мобильный браузер).
2. Загрузи в него все файлы из этого архива, сохранив структуру папок
   (важно, чтобы `.github/workflows/build.yml` оказался именно в этом пути —
   в веб-интерфейсе GitHub можно загружать сразу целыми папками через
   "Add file → Upload files", перетаскивая содержимое).
3. Открой вкладку **Actions** в репозитории — сборка запустится
   автоматически при первом пуше (или нажми "Run workflow" вручную).
4. Дождись зелёной галочки (обычно 2-4 минуты — устанавливается
   докер-образ pspdev с готовым тулчейном).
5. Зайди в завершившийся workflow → внизу раздел **Artifacts** →
   скачай `nightshift-prx.zip`. Внутри будет `nightshift.prx`.

Всё это прекрасно работает с телефона — GitHub Actions выполняется
на серверах GitHub, твоему Android нужен только браузер.

## Установка на PSP

1. Скопируй `nightshift.prx` в `ms0:/seplugins/`.
2. Скопируй `nightshift.ini` туда же (по желанию — иначе используются
   значения по умолчанию).
3. Открой `ms0:/seplugins/game.txt` (или `vsh.txt` для эффекта в самом XMB)
   и добавь строку:

   ```
   ms0:/seplugins/nightshift.prx 1
   ```

4. Перезагрузи PSP. Плагин включится вместе с игрой/XMB.

## Что можно улучшить дальше

- Сейчас фильтр честно перебирает пиксели каждого кадра в C — это самый
  простой, но не самый быстрый способ. Если появятся тормоза в играх,
  следующий шаг — оптимизация через VFPU/ASM или заменить попиксельную
  обработку на полупрозрачный "оверлей" через sceGu (примерно как рисуют
  экраны OSD в CwCheat).
- Можно добавить горячую клавишу (например, комбинацию с HOME) для
  переключения плагина без правки .ini — читать `sceCtrlPeekBufferPositive`
  в отдельном потоке.
- Стоит протестировать на PPSSPP с включённым режимом эмуляции CFW-плагинов
  либо на реальной консоли — адреса NID могут отличаться на разных
  прошивках, тогда `sctrlHENFindFunction` может не найти функцию и потребуется
  fallback на прямой NID-хук через `module_start` библиотеки sceDisplay.
